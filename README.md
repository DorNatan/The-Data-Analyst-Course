# The Data Analyst Course

This project is a personal collection of exercises and solutions from the "Data Analyst" course on Udemy. It includes Jupyter notebooks covering a range of data analysis topics.

## Notebook overview
- `apis-homework-solution.ipynb` – examples of calling APIs from Python
- `data-viz-homework-solution.ipynb` – plotting exercises covering bar, line and area charts
- `loan-data-example-with-numpy-complete.ipynb` – using NumPy to analyse loan data
- `preprocessing-data-with-numpy-complete.ipynb` – data cleaning with NumPy
- Additional notebooks demonstrate Python basics, statistics, working with arrays and text, and more.

Datasets referenced by the notebooks are not included.
